An entry for the [make.fun bounty "The Robot Vacuum's Funniest Excuse"](https://make.fun/bounty/u-eager-stork-81-9647-the-robot-vacuum-s-funniest-9822fbd2): the funniest single-line excuse a robot vacuum gives for missing a spot, max 120 characters.

## The entry

> My sensors say that spot is haunted. I am a vacuum, not an exorcist.

## How to run

```sh
node main.ts
cat /output/entry.txt
```

`main.ts` writes the single entry line to `/output/entry.txt` and validates the 120-character gate before writing. Requires Node 22.18 or later (it runs TypeScript as-is).
